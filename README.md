# INPOWAR

Browser FPS war atmosphere prototype.

## Run
Open `index.html` through a local web server or GitHub Pages. The game uses Three.js from jsDelivr.

## Current
- First-person 3D scene
- PC movement and mouse look
- Mobile HUD controls
- Destroyed buildings and rubble
- Fog/smoke atmosphere
- Projectile shooting/reload
- Responsive rendering

## Next
Aircraft flyovers, explosions, weapon audio, footsteps, terrain generation, improved mobile camera, particles and performance profiles.
